## Características principales

- **Detalles de proyectos**: Obtén información detallada sobre la ubicación y la infraestructura del I2TEC.
- **Últimas noticias**: Permite a los usuarios dirigirlos a las noticias más recientes donde el I2TEC se encuentra.
- **Redes sociales**: Conoce las redes oficiales donde podrás informarte sobre el centro.

## Para empezar

### Prerequisitos

- Bun (es nuestra recomendación por su eficiencia y rapidez)

	- En Linux/macOS:
  ```sh
  curl -fsSL https://bun.sh/install | bash
  ```

	- En Windows:
	```powershell
	powershell -c "irm bun.sh/install.ps1 | iex"
	```

### Instalación

1. Clona el repositorio

   ```sh
   git clone https://github.com/JhonRomero26/i2tec-frontend.git
   ```

2. Instala los paquetes de bun

   ```sh
   bun install
   ```

3. Ejecuta el proyecto
   ```sh
   bun run dev
   ```
